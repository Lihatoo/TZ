# rust开发环境

```
Rust + Tokio + clap
Mihomo
Clash YAML profile
start / stop / status / log
node list / select
```

**现在使用一个 Package，包含一个 Library target 和一个 Binary target。**
 不使用 Workspace，也不使用多 Bin。
